## 1. 研究問題

> 媒體報導語氣（AvgTone）與衝突結構指標（GoldsteinScale）惡化後，是否能預測該國國內抗議事件（CAMEO Root Code = 14）在未來數週增加？

分析分為兩個主軸：
- **主軸 A**：五個目標國的國內抗議前兆分析
- **主軸 B**：國際衝突升級前兆分析（CAMEO code > 15）

### 2.2 資料決策

**決策 1：protest_count 限定國內（country_1 == country_2）**  
原因：跨國抗議（如土耳其人抗議以色列）占土耳其所有抗議的 74%，與國內社會動盪無關。

## 3. 分析方法

### 3.1 CCF（Cross-Correlation Function）

**輸出**：`output/ccf_granger/ccf_{x_var}_to_protest.parquet`、`figures/fig4_ccf_heatmap.png`

**計算公式**：
```
CCF(k) = corr( x(t-k), protest(t) )   k = 0, 1, ..., 12 週
```
lag_k 的正值代表：x 在 k 週前的值與當週抗議數的相關係數。

**窗口設計（重要決策）**：

| 版本 | 窗口 | 問題 |
|---|---|---|
| 現行| **爆發前 52 週 + 爆發後 12 週** | X（tone 惡化）在前，Y（protest 爆發）在後，符合因果方向 |

**窗口結構示意**：
```
──────────────────────────────┬──────────────
  tone 逐漸惡化（X 訊號）      │ 爆發日  protest 爆發（Y）
──────────────────────────────┴──────────────
        爆發前 52 週                爆發後 12 週
```


### 3.2 Granger Causality Test

**輸出**：`output/ccf_granger/granger_summary.parquet`

H₀：x 的歷史值不能改善對 protest_count 的預測（x 不 Granger-cause protest）  
H₁：拒絕 H₀，x 具有統計上的因果可預測性

**前處理**：以 ADF 檢定自動差分至平穩（`stationarity_diff()`），回報差分階數 d。

**窗口設計**：與 CCF 一致，爆發前 52 週 + 爆發後 12 週（共 64 週），確保兩個方法可直接對比。  
max_lag = 12 週，報告各 lag 中最小 p-value（SSR-based F-test）。  
**多重比較校正**：每個（變數, 國家）對跑 12 個 lag，回報最小 p，採 Bonferroni lag 內校正 α' = 0.05/12 ≈ 0.004。

#### ADF 差分結果（差分階數 d 與有效樣本數）

**說明**：大多數序列為定態（d=0）；阿根廷 avg_tone、智利 avg_goldstein、黎巴嫩 avg_tone 與 avg_goldstein 需一階差分，有效樣本 63 週，損失極小，不影響 max_lag=12 的 Granger 分析。

### 4.4 Permutation Test（CCF 預測價值基準）

> **方法**：從各國完整時序中排除爆發窗口後，隨機抽取 100 個 64 週非爆發期窗口，計算每個窗口的 CCF（ADF 差分、排除 lag_0、取 lag 1–12 最負值），建立 null 分布。爆發期 CCF 落在 null 分布 5th percentile 外（即比 95% 的隨機窗口更負），判定為具預測價值。

| 國家 | avg_tone 爆發r | null p5 | 預測價值 | avg_goldstein 爆發r | null p5 | 預測價值 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 斯里蘭卡 | −0.388 | −0.465 | ✗ | −0.131 | −0.313 | ✗ |
| 阿根廷 | −0.160 | −0.358 | ✗ | −0.116 | −0.326 | ✗ |
| **智利** | **−0.564** | −0.268 | **✅** | −0.172 | −0.365 | ✗ |
| 土耳其 | +0.078 | −0.386 | ✗ | −0.144 | −0.409 | ✗ |
| 黎巴嫩 | −0.242 | −0.505 | ✗ | −0.158 | −0.288 | ✗ |

**顯著數**：avg_tone 1/5（智利）；avg_goldstein 0/5。α=0.05 下期望假陽性 0.5 個。

**黎巴嫩說明**：Granger 通過 Bonferroni 校正（p=0.0004），但 permutation test 不顯著。原因在於黎巴嫩歷史時序本身波動大，和平期隨機窗口的 null p5 已達 −0.505，使爆發期 −0.242 不算特別極端。兩個方法結論不一致，顯示黎巴嫩的訊號在「條件預測力」上有效，但在「相對於歷史基準的極端程度」上不突出。

**Bonferroni 校正後**：主軸 B 無任何項目通過校正。ARM↔AZE（p=0.012）、IND↔PAK（p=0.010）、USA↔IRN（p=0.020）原始 p 值偏低，作為探索性方向性證據，搭配 CCF 強負相關（ARM↔AZE r=−0.578、IND↔PAK r=−0.466、USA↔IRN r=−0.432）支持前兆假說。

### 5.4 Permutation Test（CCF 預測價值基準）

> **方法**：同主軸 A，從各衝突對完整雙邊時序中排除爆發窗口後，隨機抽取 100 個 64 週非爆發期窗口，取 lag 1–12 最負值建立 null 分布，以 5th percentile 為門檻。

| 衝突 | avg_tone 爆發r | null p5 | 預測價值 | avg_goldstein 爆發r | null p5 | 預測價值 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| RUS↔UKR | −0.182 | −0.329 | ✗ | −0.155 | −0.414 | ✗ |
| ISR↔PSE | −0.202 | −0.550 | ✗ | −0.167 | −0.576 | ✗ |
| **ARM↔AZE** | **−0.568** | −0.489 | **✅** | −0.370 | −0.540 | ✗ |
| **IND↔PAK** | **−0.466** | −0.372 | **✅** | −0.250 | −0.272 | ✗ |
| USA↔IRN | −0.432 | −0.468 | ✗ | −0.441 | −0.481 | ✗ |

**顯著數**：avg_tone 2/5（ARM↔AZE、IND↔PAK）；avg_goldstein 0/5。α=0.05 下期望假陽性 0.5 個。

**USA↔IRN 邊緣案例**：爆發r = −0.432，null p5 = −0.468，差距僅 0.036，接近但未達門檻。

| | 測試數 | α=0.05 期望假陽性 | avg_tone 顯著 | avg_goldstein 顯著 |

## 6. 研究限制

### 6.1 Granger 檢定的適用性限制

**條件預測門檻過高**：Granger VAR 問的是「在控制 Y 自身自迴歸結構之後，X 的歷史是否仍有增量預測力（conditional predictive power）」，門檻比 CCF 的邊際相關（marginal correlation）嚴格。在 64 週、高噪音的週頻抗議資料中，Y 自身的 AR 結構已消耗大量自由度，導致 Type II error 偏高。CCF 問的問題（x 的衝擊能否預測 k 週後的 y）更直接對應早期預警研究目的，為本研究主要推論依據；Granger 結果作為方向性輔助佐證。

**CCF 與 Granger 同樣需要 ADF 差分**，差分後兩者皆在「變化量」維度運算。即便如此，差分後 CCF 仍找到 r ≈ −0.6 的顯著共動，說明訊號存在於衝擊層次，並非僅在累積趨勢中。

**大 lag 下自由度不足**：測試 lag=k 時，Granger VAR 需消耗 k 期觀測值與 2k+1 個參數，分母自由度（df₂）隨 lag 增大快速下降：

| 測試 lag | 可用觀測數 | VAR 參數數 | 分母自由度（df₂） |
|----------|-----------|-----------|-----------------|
| lag = 4  | 63 − 4 = 59 | 2×4+1 = 9  | **50** |
| lag = 8  | 63 − 8 = 55 | 2×8+1 = 17 | **38** |
| lag = 12 | 63 − 12 = 51 | 2×12+1 = 25 | **26** |

lag=12 時 F 檢定為 **F(12, 26)**，達到 80% 統計檢力所需效果量（partial η²）約 0.35，屬大效果門檻。主軸 A 唯一通過 Bonferroni 校正的黎巴嫩 avg_tone（best_lag=9, p=0.0004）其 F 檢定為 **F(9, 31)**（df₂=31）；擴大窗口至 104 週的 robustness check p=0.0055，至 156 週訊號消失（p=0.28），顯示訊號集中於爆發前窗口，擴大後被平靜期稀釋。本質原因並非差分損失資料（d=1 僅少 1 筆），而是「窗口 64 週」與「大 lag 消耗自由度」疊加所致。

### 6.2 其他限制

- **avg_tone / avg_goldstein 為全量平均**：未依 relation_code 篩選，涵蓋所有國際事件，可能稀釋針對性訊號。
- **n_material_conf 排除 Granger**：與 Y（escalation_count）定義重疊，顯著結果不具獨立前兆意義。
- **媒體量特徵（n_mentions_total 等）未納入**：媒體曝光量與抗議事件存在反向因果疑慮（事件發生 → 媒體量增加），難以詮釋為前兆訊號，故保留於後續分析討論。
